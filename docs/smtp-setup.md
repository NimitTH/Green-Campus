# ตั้งค่าอีเมล (SMTP) สำหรับ Supabase Cloud

อีเมลสมัครสมาชิกและลืมรหัสผ่านส่งโดย Supabase Auth ตอนพัฒนาบนเครื่อง (local) อีเมลทุกฉบับไปอยู่ใน
Mailpit ที่ http://127.0.0.1:54324 ไม่ต้องตั้ง SMTP และไม่มีค่า SMTP ในโค้ด

บน Supabase Cloud อีเมลในตัวใช้ได้แค่ทดสอบ (จำกัดต่ำมาก และอาจส่งได้เฉพาะสมาชิกทีมโปรเจกต์) จึงต้องตั้ง
custom SMTP ก่อนเปิดให้นักเรียนสมัครจริง (spec 8.6)

## 1. เลือกผู้ให้บริการ SMTP

วิทยาลัยไม่มีโดเมนของตัวเอง ให้เลือกผู้ให้บริการที่มีครบทุกข้อ (ตรวจเงื่อนไขล่าสุดบนเว็บผู้ให้บริการก่อนตัดสินใจ):

- ยืนยันผู้ส่งแบบอีเมลเดียว (single sender verification) ได้ โดยไม่ต้องยืนยันโดเมน
- มีแพ็กเกจฟรีที่ส่งได้พอสำหรับวันสาธิต (ประมาณจำนวนนักเรียนที่จะสมัครพร้อมกัน x 2 สำหรับสมัคร + ลืมรหัส)
- ให้ค่า SMTP (host, port, username, password/API key) ไม่ใช่แค่ HTTP API
- อนุญาตอีเมลธุรกรรม (transactional) และไม่บังคับใส่ข้อความโฆษณาในอีเมล
- อ่านข้อกำหนดเรื่องการใช้ที่อยู่ผู้ส่งจากผู้ให้บริการอีเมลฟรี (เช่น Gmail) บางเจ้าส่งได้แต่ถูกจัดเป็นสแปมง่าย

จดชื่อผู้ให้บริการที่เลือกและเหตุผลไว้ใน README (ยังไม่กำหนดตายตัวในเอกสารนี้)

## 2. ใส่ค่า SMTP ใน Supabase Cloud

1. เปิดโปรเจกต์ใน Supabase Dashboard
2. ไปที่ **Authentication → Emails → SMTP Settings** แล้วเปิด **Enable custom SMTP**
3. กรอก
   - Sender email: อีเมลผู้ส่งที่ยืนยันกับผู้ให้บริการแล้ว
   - Sender name: `Green Campus`
   - Host, Port (ปกติ 587), Username, Password ตามที่ผู้ให้บริการให้มา
4. กด Save

รหัสผ่าน SMTP เก็บใน Dashboard เท่านั้น ห้ามใส่ใน git หรือไฟล์ `.env.example`

## 3. ปรับขีดจำกัดอีเมลต่อชั่วโมง

หลังเปิด custom SMTP ค่าเริ่มต้นราว 30 อีเมลต่อชั่วโมง

1. ไปที่ **Authentication → Rate Limits**
2. ปรับ **Rate limit for sending emails** ให้พอกับจำนวนคนที่คาดว่าจะสมัครพร้อมกันในวันสาธิต
   แต่ไม่เกินโควตาของแพ็กเกจผู้ให้บริการ SMTP
3. กด Save

## 4. ตั้ง URL ให้ลิงก์ในอีเมลกลับมาที่เว็บ

ไปที่ **Authentication → URL Configuration**

- Site URL: URL ของเว็บบน Vercel เช่น `https://<ชื่อโปรเจกต์>.vercel.app`
- Redirect URLs: เพิ่ม `https://<ชื่อโปรเจกต์>.vercel.app/**` (และ `http://localhost:3000/**` ถ้าทดสอบจากเครื่อง)

ลิงก์ในอีเมลจะพาไปที่ `/auth/callback` แล้วต่อไปหน้า `/dashboard` (สมัคร) หรือ `/reset-password` (ลืมรหัส)

## 5. เช็กลิสต์ทดสอบ

ใช้อีเมลภายนอก 2 บัญชี (คนละผู้ให้บริการ เช่น บัญชีหนึ่งของ Gmail อีกบัญชีของ Outlook) และไม่ใช่สมาชิกทีม Supabase

- [ ] บัญชีที่ 1: สมัครที่ `/register` → ได้อีเมลยืนยันภายใน 1-2 นาที (ดูโฟลเดอร์ Spam ด้วย)
- [ ] กดลิงก์ในเบราว์เซอร์เดียวกับที่สมัคร → เข้า `/dashboard` ได้ทันที
- [ ] บัญชีที่ 1: ออกจากระบบ → `/forgot-password` → ได้อีเมลตั้งรหัสใหม่ → ตั้งรหัสใหม่ → เข้าสู่ระบบด้วยรหัสใหม่ได้
- [ ] ทำซ้ำทั้งหมดกับบัญชีที่ 2
- [ ] ผู้ส่งในอีเมลแสดงเป็น `Green Campus` และลิงก์ชี้ไปที่ URL ของ Vercel ไม่ใช่ localhost
- [ ] จดผลการทดสอบ (วันที่, ผู้ให้บริการ, ค่าขีดจำกัดที่ตั้ง) ไว้ใน README

## แผนสำรอง (spec 8.6)

ถ้าอีเมลมีปัญหาในวันสาธิต ปิดการยืนยันอีเมลชั่วคราวที่ **Authentication → Sign In / Providers → Email →
Confirm email** (ไม่ต้องแก้โค้ด: หน้า `/register` จะพาเข้า `/dashboard` ทันทีเมื่อไม่ต้องยืนยัน)
แล้วเปิดกลับหลังสาธิต
